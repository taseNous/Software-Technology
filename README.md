# 📚 **LibConn**
## Project Description
The project we are implementing concerns the management of a library and is the
"intermediary" between those who read books and those who have books to borrow. 
Its purpose is to add value to the books that remain unused in libraries, and to 
provide an inexpensive alternative to reading books. Users will be able to register 
as readers or libraries. A reader will be able to borrow books using some "monetary 
resources". Still, they will be able to view the books available for borrowing, add 
favorite authors, books, book categories, rate books and write short reviews about 
them.A reader will be able to borrow books from libraries, choose the borrowing time 
and extend it. For each book the user will be able to see its details in detail. 
Another feature will be that the user will be able to search for books and can receive 
book suggestions. In addition, he will be able to see what other users are reading or 
have read in the past, as well as see what books he has borrowed in the past and what 
books he owes. Conversely, users registered as libraries will be able to add or remove 
from available books and manage borrowing requests. Finally, problem solving and "help" 
will be provided through the program.
